# rec/ — video explicativo

Este directorio contiene el video asciinema de **netespnow: una red fractal sin IP** y el reproductor
que se usa en la página del proyecto.

- `netespnow.cast`: grabación original (asciicast v2).
- `netespnow.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:00. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
